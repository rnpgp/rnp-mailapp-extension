OpenPGP for Apple Mail, native and polished

RNP brings signing, encryption, and key management to Mail.app on macOS — built on the audited librnp engine, fully sandboxed, and free of telemetry.

Everything OpenPGP, nothing in your way

Key management, trust decisions, and message security that live where your email already does.

Key management

Generate RSA-3072 or ECDSA P-256 keys, import and export armored keys, rotate subkeys, extend expiry, and revoke — all from a native key manager.

Trust verification

Trust-on-first-use with manual fingerprint verification. If a key changes for an address you know, encryption is blocked until you confirm it.

Keyserver support

Publish your key and discover recipients' keys over VKS (keys.openpgp.org), HKPS, and Web Key Directory — all over HTTPS.

Accessibility

VoiceOver-aware controls and labels throughout the app, with automated accessibility audits running in the UI test suite.

Localization

Fully localized in 11 languages: English, Deutsch, Español, Français, Italiano, 日本語, 한국어, Português, Русский, 简体中文, and 繁體中文.

Privacy-first

No telemetry, analytics, or crash reporting. The only network traffic is the keyserver queries you initiate, and your passphrase never leaves the Keychain.

Get started in three steps

From download to your first signed and encrypted message in a few minutes.

1

Install the app

Download the signed, notarized DMG and drag RNP into Applications. Details in the installation guide.

2

Create or import a key

Generate an RSA or ECDSA key pair whose user ID matches your mail address, or import an existing key. See usage.

3

Enable the extension

Check RNP OpenPGP in Mail → Settings → Extensions, then sign and encrypt from the compose window. How-to.
