# App Store Screenshots Checklist — RNP

Mac App Store screenshots must be at least **1280×800** pixels (16:10).
Capture on a clean macOS desktop using a demo account; do not show real email
addresses, keys, or passphrases.

## Required Screenshots

1. **Keys tab** — main key manager showing a generated or imported key with
   user ID, fingerprint, and verification status.
2. **Recipients / key detail** — importing a public key or viewing a key’s
   detail sheet with the fingerprint and verification badge.
3. **Mail compose with security banner** — composing a message in Mail with
   the security button menu open, showing **Sign** and **Encrypt** options.
4. **Onboarding / enable extension** — Mail → Settings → Extensions with
   **RNP OpenPGP** checked, or a short in-app note explaining how to enable the
   extension.

## Optional but Recommended

- Decrypted received message with the green verification banner.
- Key conflict warning (orange banner) showing how the app handles key changes.

## Production Notes

- Use a demo Apple ID and a throwaway PGP key pair for screenshots.
- Do not include Menu Bar extras, notification badges, or unrelated personal
  information.
- Keep UI text in the primary localization (English) unless localizing the
  store page.
