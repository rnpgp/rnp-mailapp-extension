Getting Started

You'll be encrypting files and email in under five minutes.

1. Install

Two ways to install RNP on macOS:

# Option A: Homebrew (recommended)
brew install --cask rnp

# Option B: Direct download
# Download from https://github.com/rnpgp/rnp-mailapp-extension/releases/latest
# Open the DMG, drag RNP to /Applications, eject, launch.

macOS 14 or later. Both builds are signed and notarized.

2. Generate a key

On first launch, RNP walks you through creating your first key:

  1. Open RNP from Applications.
  2. Pick Create a new key.
  3. Enter your name and email. This is how others will find your key.
  4. Choose a passphrase. Touch ID unlocks the keyring afterwards.
  5. Pick an algorithm — Ed25519 is the modern default. Pick Hybrid PQ for post-quantum readiness.

3. Enable RNP for Mail

RNP for Mail adds lock icons to encrypted and signed messages in Apple Mail. After installing, you have to grant Mail permission:

  1. Open RNP at least once. (You just did.)
  2. Open System Settings → Privacy & Security → Extensions.
  3. Find RNP for Mail under Added Extensions.
  4. Toggle Mail on. Restart Mail.

RNP shows this sheet automatically after onboarding, with a deep-link button to skip the navigation.

4. Encrypt a file

  1. Click File Tools in RNP's sidebar.
  2. Drag a file in.
  3. Pick the recipients (their public keys must be in your keyring — fetch via WKD if not).
  4. Click Encrypt. Save the .pgp file.

For a no-UI workflow, use the Finder Quick Action: right-click any file → Quick Actions → Encrypt File.

5. Send an encrypted email

  1. Make sure RNP for Mail is enabled (step 3).
  2. Compose a message in Mail to someone whose key you have.
  3. The lock icon in the compose toolbar toggles encryption.
  4. Send. The recipient sees the lock icon on arrival.

Importing an existing key from GnuPG

RNP can read keys from your existing GnuPG keyring at ~/.gnupg read-only. From RNP:

  1. Toolbar → Import → From GnuPG or RNP keyring.
  2. Pick the keys to import.
  3. Confirm. The originals are not modified.
